Part 2 Lab Materials

POLS 081 · Class Meeting #11 · 2:45–4:00 pm

Download the lab files, the guide to Example 2, and extra practice on merging datasets.

In the lab we take a question from data to evidence: summary statistics → one good figure → one statistical test, in R, RStudio and Quarto.

1. Get the lab files

Download pols081-lab.zip

  1. Unzip it. On Windows, right-click the file and choose Extract All…. Don’t work inside the zip.
  2. Move the pols081-lab folder somewhere easy to find, like Documents. Avoid OneDrive folders if you can.
  3. Double-click pols081-lab.Rproj to open the folder in RStudio.
  4. In the Files pane, open lab-handout.qmd.

The folder contains:

File What it is
lab-handout.qmd The lab handout: Example 1 (worked), Example 2 (you fill in the code), Workshop Questions
merging-data.qmd Extra practice: combining two datasets
data/ The datasets used in the handouts and the visualization guide
bib/lab.bib References for the handouts
TipCan’t run R on your laptop? Use Posit Cloud

The lab handout is also in its own GitHub repository, https://github.com/gamusu/pols081-ssql-lab, which you can open in your browser with Posit Cloud:

  1. Go to https://posit.cloud and log in (a free account is fine).
  2. Click New Project → New Project from Git Repository, paste https://github.com/gamusu/pols081-ssql-lab, and click OK.
  3. In the Files pane, open setup.R and click Source. Wait a few minutes for the packages to install.
  4. Open lab-handout.qmd and click Render.

4. The data

All the datasets are real and public. They were downloaded and cleaned on November 17, 2026, by the script R/build_lab_data.R in the workshop project, which records every source and step.

File Rows Source
adaptation_aid.csv One row per country receiving adaptation aid OECD Rio markers (DAC members, 2020–2024); ND-GAIN; World Bank; UN M49
renewables.csv One row per country, 2021 World Bank, World Development Indicators
co2.csv One row per country, 2023 World Bank, World Development Indicators (emissions from EDGAR)
co2_trend.csv One row per country per year, 2018–2023 Same as co2.csv; used in the visualization guide
sids_list.csv One row per small island developing state UN Statistics Division, M49

Codebooks for each file are in the handouts.
